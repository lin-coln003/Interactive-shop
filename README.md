# Shopping List App

## Description
This is an interactive shopping list application that allows users to manage shopping items, track purchased items, and calculate the total cost of purchased products.

## Features
- Add items with a name and price.
- Validate item names and prices.
- Prevent duplicate item names.
- Mark items as purchased using checkboxes.
- Calculate the total cost of purchased items.
- Edit existing items.
- Cancel editing without saving changes.
- Clear the entire shopping list.
- Save the shopping list using localStorage so items remain after refreshing the page.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add, edit, or mark shopping items as purchased.

## Data Storage
The application uses the browser's localStorage to save the shopping list. Saved items can remain available when the page is refreshed in the same browser.
